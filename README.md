# 数学试卷 PDF 直链仓

1-6 年级数学期中 / 期末试卷，共 215 套（人教版 113 套、北师大版 102 套），
每套含「试卷」与「答案解析」两个 PDF，合计 430 个文件。

本仓库只做静态直链托管，配合「汉语拼音拼读练习」应用里的「数学试卷」页使用，
链接形如：https://sxx100200.github.io/math-papers/papers/g1/u/106.pdf

目录规则：`papers/<年级 g1-g6>/<册次 u 上册 / d 下册>/<编号>.pdf`，
带 `-ans` 后缀的是答案解析。编号沿用原始试卷题号，在同年级同册次内唯一。

试卷由使用者自行收集整理，本仓库不主张对原内容的版权；
如 rights holder 认为不应托管，请在 issues 里说明，收到即移除。

语文卷在另一个仓库：https://github.com/sxx100200/pinyin-papers
